Trusted Security Manager (TSM).

This module provides a cross-vendor ConfigFS interface for generating confidential-computing attestation reports. Userspace writes a request blob under /sys/kernel/config/tsm/report/$name/inblob and reads back the signed report from outblob, with optional knobs like provider and generation.

For more information about the interface, checkout Linux’s documentation.
