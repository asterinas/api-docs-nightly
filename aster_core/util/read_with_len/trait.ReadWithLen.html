A trait providing the ability to read a specified number of bytes.

fn read_with_len( &self, offset: usize, writer: &mut VmWriter<'_>, len: usize, ) -> Result<()>

Reads exactly len bytes at the specified offset into the given writer.

Returns Ok(()) without reading if len is zero. Otherwise, this has the same no-short-read contract as VmIo::read.

On success, advances the writer by len without changing its end boundary. On error, leaves the writer’s cursor and boundary unchanged, but bytes in the destination may already have been modified.

§Panics

Panics if len exceeds the writer’s available space.
