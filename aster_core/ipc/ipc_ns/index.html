Module ipc_ns 

Source
Expand description

Defines the IPC namespace abstraction.

An IPC namespace isolates System V IPC resources from other namespaces. It currently manages semaphore sets only, while message queues and shared memory remain to be added.

Each namespace stores its semaphore sets in a per-namespace map keyed by IPC key and uses a dedicated ID allocator to assign semaphore identifiers.
