The eventfd file object and its counter semantics.

An eventfd maintains a 64-bit counter. Userspace writes add to the counter, while reads either consume the whole counter or decrement it by one in semaphore mode. Both operations may wait according to the file’s status flags.

EventFile is the file-descriptor-facing object behind an eventfd. Its KernelEventFile component owns the counter and notification state shared with in-kernel producers and consumers.
