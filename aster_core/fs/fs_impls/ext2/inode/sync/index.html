Writeback and reclaim for ext2 inodes.

This module contains the inode paths that make in-memory state durable and reclaim deleted inodes. Writeback must keep xattrs, data pages, indirect metadata, and inode-table state ordered consistently; reclaim must release all storage owned by a zero-link inode exactly once.
