Structures for the extended file attribute retrieval system call statx.
StatxFlags 🔒
Flags can be used to influence a pathname-based lookup. Flags can also be used to control what sort of synchronization the kernel will do when querying a file on a remote filesystem.
StatxMask 🔒
Flags to be stx_mask. Query request/result mask for statx() and struct statx::stx_mask. These bits should be set in the mask argument of statx() to request particular items when calling statx().
