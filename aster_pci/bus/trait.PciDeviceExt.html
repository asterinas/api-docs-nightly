fn acquire_msix_capability( self: &Arc<Self>, ) -> Result<Option<CapabilityMsixData>>

Acquires necessary resources to build the MSI-X capability data, if the capability exists.

Returns Ok(None) if the device has no MSI-X capability. Dropping the returned capability disables its interrupts, releases its IRQ lines, and allows it to be acquired again.

§Errors
  • InvalidArgs if the MSI-X table or pending bit array references a missing BAR or an I/O BAR instead of a memory BAR.
  • AccessDenied if the required BAR I/O memory cannot be acquired, or the MSI-X capability is already acquired.
