pub fn emit(dev: &dyn AnyDevice, action: UeventAction) -> Result<()>
Expand description

Emits a device event with the specified action.

Returns Ok(()) without emitting an event if the device has no bus or class subsystem.

Returns Error::NotAdded if the device is not registered or has already been removed. Returns Error::MemoryBudgetExhausted if the event exceeds the entry count or byte limit. Propagates errors from Bus::append_uevent_vars(), Class::append_uevent_vars(), and DeviceType::append_uevent_vars_fn.
